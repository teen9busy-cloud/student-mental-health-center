# 경상남도교육청 학생정신건강 전담센터 통합관리 플랫폼 (Demo)

> **경상남도교육청** 위탁 사업  
> **진주 경상국립대학교병원** (서부경남 11개 시·군) · **창원 경상국립대학교병원** (동부경남 7개 시·군) 운영

---

## 1. 프로젝트 개요

본 플랫폼은 소방상담플랫폼(**시모니; simony1**)의 검증된 안정성과 정갈한 디자인 시스템을 기반으로, 학생정신건강 전담센터의 고유한 임상 및 행정 워크플로우에 최적화하여 개발된 **SaaS 형태의 웹 플랫폼 데모 버전**입니다.

단순 데이터베이스 적재 방식에서 벗어나 실제 상담센터 현장처럼:
1. **내담자(학생/보호자/학교) 접수 등록**
2. **심리검사 점수 직접 입력 및 절단점(Cut-off) 기반 실시간 자동 수치화/위험군 판정**
3. **엑셀/CSV 일괄 업로드 파서 및 자동 매핑**
4. **회기별 모니터링 상담 일지 및 소아청소년정신과 전문의(센터장) 자문 피드백**
5. **경남 18개 시·군별 분포, 학교급별 교차분석, 사전-사후 점수 호전 추이, 교육청 보고서(CSV) 원클릭 출력**

등의 전체 라이프사이클을 완성도 높게 시연할 수 있도록 구현되었습니다.

## 2. 조직 및 사용자 역할 (데모 스위처 지원)

상단 헤더의 **[시연 권한]** 드롭다운을 통해 즉시 역할을 전환하여 시연할 수 있습니다:

| 역할 | 명칭 및 담당자 | 주요 권한 및 업무 |
|---|---|---|
| **센터장 (의사)** | 김진우 교수 (소아청소년정신과 전문의) | 전체 위기현황 총괄, 고위험군 진료 연계, 전문의 자문/소견 등록, 교육청 보고서 승인 |
| **임상심리사** | 박서연 (1급 정신건강임상심리사) | 심리검사(AMPQ-II, K-BDI-II, RCMAS, C-SSRS, K-CBCL) 실시, 점수 수치화, 엑셀 일괄 업로드, 심리평가보고서 작성 |
| **사회복지사** | 이민호 (1급 정신건강사회복지사) | 학생 및 보호자 초기 접수, 학교(Wee클래스) 연계, 대면/전화/방문 모니터링 일지 작성 |
| **교육청 담당자** | 정재훈 장학사 (경남교육청) | 경남 18개 시군 관할 학생 및 위험군 통계 모니터링, 실적 보고서 다운로드 |

## 3. 핵심 기능 안내

### ① 대시보드 (Dashboard)
- 경남 18개 시·군 총괄 지표 (총 관리학생수, 고위험군, 주의군, 누적 검사/모니터링)
- **자살/자해 위기군(C-SSRS 4단계 이상 등) 긴급 알림 배너** 및 즉각 조치 테이블
- 경남 시·군별 학생 분포 바 차트

### ② 내담자(학생) 관리
- 기본 인적사항, 경남 18개 시군 소속 학교(초·중·고), 학년/반, 보호자 연락처, 의뢰경로, 주 호소문제
- 학생별 상세 프로필 팝업: **심리검사 이력**과 **모니터링 누적 일지 타임라인**을 한눈에 통합 조회

### ③ 심리검사 등록 및 자동 수치화 (Scoring Engine)
- 지원 척도:
  - **AMPQ-II (학생정서·행동특성 2차 심층검사)**: 우울/불안/품행/자살자해 하위척도 합산 및 절단점 자동 판정
  - **K-BDI-II (한국판 청소년 우울척도)**: 경도/중등도/중증 우울 자동 분류
  - **RCMAS (아동·청소년 불안척도)**
  - **C-SSRS (콜롬비아 자살위험도 평가척도)**: 긴급 위기단계 선별
  - **K-CBCL (아동청소년 행동평가척도 T점수)**
- **엑셀/CSV 일괄 업로드**: 드래그 앤 드롭으로 파일을 올리면 자동으로 각 행의 점수를 읽고 수치화하여 매핑 테이블에 프리뷰 후 일괄 저장
- **표준 템플릿 다운로드**: 시연 현장에서 즉시 다운받아 테스트할 수 있는 CSV 양식 제공

### ④ 모니터링 및 상담 일지
- 접촉 유형(센터 대면, 전화/화상, 학교 방문, 가정 방문, 병원 연계)별 회기 기록
- 상담 요약, 학생 정서 상태, 개입 내용, **소아청소년정신과 전문의 자문 소견** 기록

### ⑤ 통계 분석 및 교육청 보고서
- 위기도별 비율 분포
- 주요 호소문제 빈도수
- **학교급(초·중·고) × 위기도 교차분석 표**
- **사전-사후 검사 점수 변화(개입 효과성 호전 그래프)**
- **경남교육청 제출용 사업 실적표 원클릭 CSV 다운로드**

## 4. 인프라 및 데이터베이스 아키텍처

- **하이브리드 모드 (Local Demo + Supabase Cloud)**:
  - 별도 서버나 네트워크 세팅 없이도 브라우저에서 즉시 **오프라인 100% 데모 시연** 가능 (풍부한 경남 더미 데이터 내장).
  - 헤더의 **[로컬 데모 모드]** 버튼을 클릭하여 본인의 Supabase Project URL과 Anon Key를 입력하면 즉시 클라우드 DB와 실시간 통신 모드로 전환됩니다.
- **SQL DDL (`sql/schema.sql`)**:
  - PostgreSQL / Supabase 표준 스키마 제공
  - 전담센터(`centers`), 경남 18개 시군(`regions`), 사용자(`users`), 학생(`clients`), 심리검사(`psych_tests`), 모니터링(`monitoring_logs`), 감사로그(`audit_logs`) 테이블 및 초기 마스터 데이터 완비
- **확장성 (Neon / Google Cloud)**:
  - `js/db.js` 어댑터 계층이 분리되어 있어 향후 대용량 데이터 적재 시 Neon Serverless Postgres 또는 Google Cloud Run / Cloud SQL 백엔드로 무중단 전환 가능

## 5. 실행 및 시연 방법

### 로컬 브라우저에서 바로 실행
1. `index.html` 파일을 크롬 등 웹 브라우저로 더블 클릭하여 엽니다.
2. 또는 터미널에서 간단한 웹 서버 실행:
   ```bash
   npx serve .
   ```
   브라우저에서 `http://localhost:3000` 접속.

### 미팅 시연 추천 순서 (5분 데모 시나리오)
1. **대시보드 소개**: 경남교육청 및 진주·창원 센터 소개, 전체 현황 및 상단 위기학생 긴급 알림 시연
2. **역할 전환**: 우측 상단에서 "사회복지사 모드" ➔ 학생 등록 ➔ 목록 확인
3. **임상심리사 모드**:
   - [심리검사 & 수치화] 탭 이동 ➔ 개별 검사 점수 입력 시 실시간으로 우울/자살위험 등급이 자동 판정되는 모습 시연
   - [엑셀 일괄 업로드] 팝업 ➔ 샘플 템플릿 다운로드 후 드래그 앤 드롭으로 수십 건이 1초 만에 자동 수치화되는 모습 시연
4. **모니터링 일지 & 의사 자문**: "센터장(의사) 모드"로 전환하여 전문의 소견 남기기
5. **통계 및 교육청 보고서**: 학교급별 교차분석, 사전-사후 호전 그래프, 원클릭 엑셀(CSV) 다운로드 시연
